# Simulador AMV Operador

App web de estudio personal (no comercial) para el examen de certificación AMV, perfil Operador. Funciona sin conexión y se puede instalar en la pantalla de inicio del teléfono.

El contenido parafrasea las guías de estudio de AMV (licencia CC BY-NC-ND); no está afiliado a AMV. Se genera con `build.py` y `build_app.py`; no edite estos archivos a mano.
